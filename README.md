# To-Do List - Task Manager

Welcome to **To-Do List**, a simple and intuitive web application designed to help you manage your daily tasks efficiently. Focusing on simplicity and usability, this application offers a hassle-free organizational experience, making task management easy and enjoyable.

## Features

- **📝 Add Tasks**: Enter your daily tasks into the list to stay organized.
- **🗑️ Remove Tasks**: Delete tasks that are no longer needed with a simple click.
- **✨ Hover Effect**: When hovering over a task, a subtle "hover" effect is applied, providing a modern and pleasant visual experience.

## Technologies Used

- **Pure JavaScript**: The application's logic and interactivity were developed entirely with JavaScript.
- **HTML5**: Basic structure of the application.
- **CSS3**: Interface styling, including the "hover" effect on task items.

## How to Use

Clone the repository to your computer and open the index.html file in your browser.

1. **Adding Tasks**:
   - Enter your task in the text field and press "Enter" or click the add button.
   - The task will appear in the list below.

2. **Completing Tasks**:
   - To mark a task as completed, click on the desired task.
   - The task will be highlighted as completed.

3. **Removing Tasks**:
   - To remove a task, click the trash icon next to the task.
   - The task will be removed from the list.
